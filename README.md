Entry for [make.fun's Make the best cooking game](https://make.fun/bounty/best-cooking-game-20261125-0137) ($250).

**Rush Hour Kitchen** is a time-management cooking game: build each order on the plate before the timer runs out. Click ingredients on the counter to add them to the dish, hit SERVE when the plate matches the order, and trash the plate when it goes wrong. 90 seconds, six recipes, combos for clean streaks.

`main.ts` copies `game/` and `screenshots/` to `/output` and writes `/output/dossier.json`.
